# KPI Calculations — Attendance / Productivity

Authoritative reference for how daily and month-to-date KPIs are computed from
the `attendance_records`, `daily_packs`, and `temp_staff` tables.

All formulas below match the runtime code in `main.py` (see `_gantt_compute_for_date`).

---

## 1. Data sources

| Table | Purpose | Key columns |
|---|---|---|
| `attendance_records` | Per-person clock in/out per day, many uploads possible | `personal_code`, `record_date`, `commute_time`, `time_to_leave`, `working_hours`, `upload_date` |
| `daily_packs` | Total production packs per date (plant-wide) | `record_date`, `number_of_packs` |
| `temp_staff` | フルキャスト / temp groups folded into Section 2 | `record_date`, `headcount`, `start_time`, `leave_time`, `total_hours` |
| `sections.json` | Roster → section mapping (id 1 = 製造１課, id 2 = 製造２課) | `codes[]` per section |

**Deduplication rule:** per (personal_code, record_date) keep only the latest
upload — `DISTINCT ON (personal_code, record_date) ... ORDER BY ... upload_date DESC`.

---

## 2. Working-hours parser

`working_hours` is stored as `"H:MM hr"` or `"H:MM"` or empty.

```
clean_wh   = strip trailing ' hr' / 'hrs' from working_hours
hours      = H + M / 60          (when matching ^\d+:\d{2})
           = 0                   (otherwise — row counts as absent)
```

---

## 3. Daily productivity (per section)

Target lines (from `main.py` docstring):

| Section | Target |
|---|---|
| 製造１課 (Section 1) | 85 P/h |
| 製造２課 (Section 2) | 35 P/h |
| Combined | 25 P/h |

```
section_hours   = Σ parsed_hours over rows whose personal_code ∈ section
                 + Σ temp_staff.total_hours (Section 2 only)
section_present = (# regular rows with hours>0) + Σ temp_staff.headcount (Sec 2)
total_packs     = daily_packs.number_of_packs for the date
section_LP      = total_packs / section_hours      (packs per hour)

# Shortfall vs target
packs_gap       = total_packs − (target × section_hours)
hours_excess    = section_hours − (total_packs / target)
```

---

## 4. MTD aggregates (month-to-date)

Window: `'YYYY-MM-01'` to chosen end date (both inclusive).

```
packs_MTD        = SUM(daily_packs.number_of_packs)  over window
section_hours_MTD= SUM of parsed_hours per (code, date) where code ∈ section
section_mandays  = COUNT(*) where parsed_hours > 0
section_LP_MTD   = packs_MTD / section_hours_MTD
daily_avg_hours  = section_hours_MTD / working_days_in_window
daily_avg_packs  = packs_MTD / working_days_in_window
hours_per_person = section_hours_MTD / section_mandays
roster_util %    = (mandays / working_days) / roster_size × 100
```

---

## 5. Per-employee performance score (Section 2)

Composite score used in HR ranking (0 – 100, higher = better).

```
attendance_rate  = days_present / working_days_in_window
volume_ratio    = MTD_hours / (working_days × reference_shift)
                  reference_shift defaults to 12 h  →  cap = 22 × 12 = 264

Score = [ attendance_rate × 0.5  +  volume_ratio × 0.5 ] × 100
```

| Band | Range | Meaning |
|---|---|---|
| A — Anchor | ≥ 85 | Irreplaceable core contributor |
| B — Core | 75 – 84.9 | Backbone of shifts |
| C — Reliable | 65 – 74.9 | Dependable regular |
| D — Partial | 50 – 64.9 | Mid-utilization / check contract |
| E — Low | < 50 | Part-time, trainee, or absent-heavy |

## 6. Data-accuracy definitions

For any window:

```
days_no_record     = working_days − (distinct dates with any row for person)
days_blank         = rows where clock_in OR clock_out OR hours is empty/unparseable
days_missing_total = working_days − days_present

rows_parseable%    = rows with valid H:MM ÷ total rows × 100
```

A perfect dataset has `days_no_record = 0` for every employee (every roster
row is generated by the PDF ingest, even on absences). "Missing" in the
current DB almost always means "rostered but absent", not a data gap.

## 7. Canonical SQL — Section 2 per-employee MTD ranking

Drop-in query (Postgres) used to produce the HR performance ranking:

```sql
WITH sec2_codes AS (
  SELECT unnest(ARRAY[
    '00000320','00000115','00000578','00000575','00000576','00000577','00000340','00000344',
    '00000351','00000372','00000376','00000378','00000386','00001703','00000356','00000649',
    '00000652','00000653','00000655','00000660','00003001','00003005','00003006','00003007',
    '00003009','00005018','00005023','00005024','00005030','00005032','00005036','00005039',
    '00005040','00005043','00005044','00005046','00005047','00005048','00005049','00000309',
    '00000112','00000324','00004062','00005017','00000326','00003010','00003011','00003012',
    '00003013','00003014','00003015'
  ]) AS code
),
params AS (
  SELECT DATE '2026-04-01' AS start_date,
         DATE '2026-04-22' AS end_date,
         22::numeric        AS working_days,
         264::numeric       AS hours_cap        -- working_days × 12h reference shift
),
latest_per_day AS (
  SELECT DISTINCT ON (personal_code, record_date)
         personal_code, full_name, record_date,
         commute_time, time_to_leave, working_hours
  FROM attendance_records, params
  WHERE record_date BETWEEN params.start_date AND params.end_date
  ORDER BY personal_code, record_date, upload_date DESC
),
parsed AS (
  SELECT l.*,
    CASE WHEN l.working_hours ~ '^\d+:\d{2}' THEN
      split_part(regexp_replace(l.working_hours,'\s*hrs?\.?\s*$','','i'),':',1)::int
      + split_part(regexp_replace(l.working_hours,'\s*hrs?\.?\s*$','','i'),':',2)::int/60.0
    ELSE 0 END AS hours,
    CASE WHEN (l.commute_time IS NULL OR l.commute_time='')
           OR (l.time_to_leave IS NULL OR l.time_to_leave='')
           OR NOT l.working_hours ~ '^\d+:\d{2}'
      THEN 1 ELSE 0 END AS bad_row
  FROM latest_per_day l
),
agg AS (
  SELECT s.code AS personal_code,
         max(p.full_name) AS name,
         COUNT(p.record_date) AS rows_found,
         COUNT(*) FILTER (WHERE p.hours > 0) AS days_present,
         COUNT(*) FILTER (WHERE p.bad_row = 1) AS days_blank,
         ROUND(COALESCE(SUM(p.hours),0)::numeric, 1) AS mtd_hours
  FROM sec2_codes s
  LEFT JOIN parsed p ON p.personal_code = s.code
  GROUP BY s.code
)
SELECT a.personal_code, a.name,
       a.days_present,
       a.mtd_hours,
       a.days_blank,
       (SELECT working_days FROM params) - a.rows_found AS days_no_record,
       ROUND((a.days_present / (SELECT working_days FROM params)) * 100, 1) AS attend_pct,
       ROUND(CASE WHEN a.days_present > 0 THEN a.mtd_hours / a.days_present ELSE 0 END, 2) AS avg_h_per_day,
       ROUND(
         ( (a.days_present / (SELECT working_days FROM params)) * 0.5
           + (a.mtd_hours   / (SELECT hours_cap    FROM params)) * 0.5
         ) * 100, 1
       ) AS perf_score
FROM agg a
ORDER BY perf_score DESC NULLS LAST;
```

## 8. Canonical SQL — Per-section daily LP with target gap

```sql
WITH params AS (
  SELECT DATE '2026-04-04' AS d,
         35::numeric AS sec2_target,
         85::numeric AS sec1_target,
         25::numeric AS combined_target
),
latest AS (
  SELECT DISTINCT ON (personal_code)
         personal_code, working_hours
  FROM attendance_records, params
  WHERE record_date = params.d
  ORDER BY personal_code, upload_date DESC
),
parsed AS (
  SELECT l.*,
    CASE WHEN l.working_hours ~ '^\d+:\d{2}' THEN
      split_part(regexp_replace(l.working_hours,'\s*hrs?\.?\s*$','','i'),':',1)::int
      + split_part(regexp_replace(l.working_hours,'\s*hrs?\.?\s*$','','i'),':',2)::int/60.0
    ELSE 0 END AS hours
  FROM latest l
),
temp_hours AS (
  SELECT COALESCE(SUM(total_hours), 0) AS h,
         COALESCE(SUM(headcount),   0) AS n
  FROM temp_staff, params
  WHERE record_date = params.d
),
packs AS (
  SELECT COALESCE(number_of_packs, 0) AS p
  FROM daily_packs, params
  WHERE record_date = params.d
)
SELECT
  (SELECT d FROM params)                                    AS record_date,
  (SELECT p FROM packs)                                     AS total_packs,
  ROUND(SUM(hours)::numeric, 2)                             AS all_regular_hours,
  (SELECT h FROM temp_hours)                                AS temp_hours,
  ROUND((SUM(hours) + (SELECT h FROM temp_hours))::numeric, 2) AS combined_hours,
  -- Section 2 only
  ROUND(((SELECT p FROM packs) /
         NULLIF(SUM(hours) FILTER (WHERE TRUE) /* add sec2 filter */ + (SELECT h FROM temp_hours), 0))::numeric, 2)
    AS sec2_LP_placeholder
FROM parsed;
-- Note: add sec2 filter as in §7 for actual section split.
```
