🤖 ChatGPT

ChatGPT Plus が必要。約3分。（キーは「アプリ用」とは別の at_… です）Needs ChatGPT Plus. ~3 min. (This key is a separate at_…, not the desktop key.)

⚠️ 普通のチャットに貼っても動きません。下の手順で Custom GPT（ChatGPT Plus 必要） を作って初めて使えます。Plus が無い場合は ChatGPT では利用不可です。⚠️ Pasting into a normal chat does NOT work. It only works after you build a Custom GPT (needs ChatGPT Plus) below. Without Plus, ChatGPT can't be used.

  1. Explore GPTs → + Create → Configure
  2. Actions → Create new action
  3. Schema → Import from URL に Schema を貼る— paste the Schema
  4. Authentication → API Key → Bearer に ChatGPT キーを貼る— paste the ChatGPT key
  5. Save → 「今日の生産数は？」"today's production?"
